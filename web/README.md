# StudentCareer AI — web app

The Next.js UI lives in this folder. **Local setup and how to use Apply** are in the repo-root guide:

**[../README.md](../README.md)**

From the repo root, after env files and `npm run saas:setup`:

```bash
cd web
npm install
npm run dev
```

Open **http://127.0.0.1:3000**. Keep `APPLY_HEADLESS=false` in `.env.local` so Chrome opens on this computer. Do not commit `.env.local`.
